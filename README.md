# Dart Practice

A collection of Dart programs written while learning the Dart programming language.

## Contents

This repository contains numbered Dart source files (`.dart`) for practicing language fundamentals and solving small programming exercises.

## Requirements

- Dart SDK

## Run a Program

From the repository folder, run a Dart file with:

```bash
dart run 1.dart
```

Replace `1.dart` with the filename you want to run.

## Purpose

These examples are part of my learning journey with Dart. I plan to organize and expand them as I practice more language features and programming concepts.
